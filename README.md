# TareasPWA - Gestor de Tareas Progressive Web App (PWA)

Aplicación web desarrollada con **Blazor WebAssembly** y **.NET 10**, implementada como una Progressive Web App (PWA) con soporte completo para funcionamiento offline, caché de recursos mediante Service Worker y diseño responsivo.

## 🚀 Características del Proyecto
- **Frontend y Arquitectura:** C# / Blazor WebAssembly Standalone.
- **Gestión de Estado y Componentes:** Modelos personalizados (`Tarea`), servicios inyectados (`TareaService`) y páginas interactivas en Razor.
- **PWA (Progressive Web App):**
  - Configuración de manifiesto (`manifest.webmanifest`) con iconos y opciones de visualización autónoma (`standalone`).
  - Registro de Service Worker para almacenamiento en caché y carga offline.
- **Interfaz de Usuario:** Utiliza Bootstrap y componentes modernos integrados en la plantilla base de Blazor.

## 🛠️ Tecnologías Utilizadas
- [.NET 10 SDK](https://dotnet.microsoft.com/)
- Blazor WebAssembly
- Visual Studio / VS Code / PowerShell
- Python (para servidor local estático de pruebas en modo producción)
